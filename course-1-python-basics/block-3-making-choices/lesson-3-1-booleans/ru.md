## Объяснение

Добро пожаловать на **Квестовые ворота**! Прежде чем выбирать путь в истории, нужно задавать вопросы вроде «Они равны?» или «Это больше?». Python отвечает **`True`** (прошёл) или **`False`** (не прошёл).

Переменные ты уже знаешь по блоку 2. Теперь ты сравниваешь значения:

| Оператор | Значение | Пример |
|----------|----------|--------|
| `==` | равно | `5 == 5` → `True` |
| `!=` | не равно | `3 != 3` → `False` |
| `>` | больше | `10 > 7` → `True` |
| `<` | меньше | `4 < 2` → `False` |
| `>=` | больше или равно | `5 >= 5` → `True` |
| `<=` | меньше или равно | `2 <= 9` → `True` |

**`and`** — оба должны быть True. **`or`** — хотя бы один должен быть True:

```python
print(True and False)   # False
print(True or False)    # True
```

**`not`** переворачивает True ↔ False — как будто переворачиваешь квестовую печать:

```python
print("not False:", not False)   # True
print("not (5 == 3):", not (5 == 3))   # True — 5 == 3 is False, not False is True
```

**Пока без `if`:** условия `if` появятся в уроке 3.2. Сегодня ты только **печатаешь** результаты сравнений.

## Уголок отладки

**Проблема:** Ты пишешь `if 5 = 5:` и получаешь `SyntaxError`.

**Причина:** Один `=` **кладёт значение в коробку** (присваивание). Чтобы **сравнить**, нужен **`==`** (два знака равенства).

**Исправление:** Для сравнения пиши `5 == 5`. Один `=` оставь для `name = "Alex"`.

## Проверь себя

Выбери лучший ответ на каждый вопрос. Сначала попробуй без подсказок!

1. Чему равно `5 == 5`?
   - **a)** `False`
   - **b)** `5`
   - **c)** Ошибка
   - **d)** `True`

2. Чему равно `3 != 3`?
   - **a)** `False`
   - **b)** `3`
   - **c)** `0`
   - **d)** `True`

3. Один знак `=` используют для…
   - **a)** Печати True или False
   - **b)** Присваивания — положить значение в переменную
   - **c)** Сравнения двух значений
   - **d)** Сложения чисел

4. Чему равно `True and False`?
   - **a)** `"True and False"`
   - **b)** `True`
   - **c)** `False`
   - **d)** `None`

5. Чему равно `True or False`?
   - **a)** `False`
   - **b)** `None`
   - **c)** Ошибка
   - **d)** `True`

---

<details><summary>Нажми, чтобы показать ответы</summary>

1. **d)** `==` проверяет равенство; `5 == 5` → `True`.
2. **a)** `!=` значит «не равно»; `3` равно `3`, значит `False`.
3. **b)** Один `=` присваивает (`name = "Alex"`); два `==` сравнивают.
4. **c)** `and` требует **оба** True; один False — результат False.
5. **d)** `or` требует **хотя бы один** True; True or False → True.

</details>
