# Варианты узоров — дополнительные задачи

**Урок:** 3.4 · **Блок:** Выбор и повторение

---

## Вариант 1: Квадратная сетка

Напечатай сетку 5×5 из звёзд (5 строк, по 5 звёзд в каждой):

```text
*****
*****
*****
*****
*****
```

**Подсказка:** внешний цикл `range(5)`, внутренний тоже `range(5)`.

---

## Вариант 2: Числовая пирамида

Печатай номер строки вместо звёзд:

```text
1
22
333
4444
55555
```

**Подсказка:** `print(row, end="")` во внутреннем цикле.

---

## Вариант 3: break

Используй `break`, чтобы остановить внешний цикл после 3-й строки — напечатаются только 3 строки.

**Подсказка:** `if row == 3: break` внутри внешнего цикла (после печати строки).
