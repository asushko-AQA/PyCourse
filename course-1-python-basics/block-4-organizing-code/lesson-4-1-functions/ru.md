## Объяснение

Добро пожаловать в **Мастерскую приключений**! В Блоке 3 ты писал ветки `if` и циклы. Теперь ты изучишь **функции** — многоразовые рецепты, которые можно запускать снова и снова без переписывания одного и того же кода.

**Комментарии:** строки, начинающиеся с `#`, — заметки для людей, Python их пропускает. В файлах starter ты увидишь `# TODO` — так отмечены места, где код пишешь **ты**:

```python
# This is a comment — Python ignores it
def draw_banner(text):
    print("===")  # title line
```

**Функция** — именованный блок шагов. Ты **определяешь** её один раз через `def`, затем **вызываешь**, когда нужны эти шаги:

```python
def draw_banner(text):
    print("===")
    print(text)
    print("===")
```

Вызов `draw_banner("Привет")` выполняет все три строки `print()` внутри функции.

### Шаг 2: Напиши draw_banner

`draw_banner(text)` принимает текст и печатает его между строками `===` — как заголовок твоего приключения. Замени `pass` тремя строками `print()` из примера выше. Сделай отступ в четыре пробела, чтобы они остались внутри функции.

### Шаг 3: Напиши ask_yes_no

`ask_yes_no(question)` печатает вопрос, ждёт `input()` и **возвращает** строку `"yes"` или `"no"`. Вызывающий код сохраняет ответ в переменную.

Строка с `input()` уже есть. Замени `return "no"` такой проверкой — `answer in ("y", "yes")` равно `True`, когда ответ `"y"` или `"yes"`:

```python
    if answer in ("y", "yes"):
        return "yes"
    return "no"
```

Затем допиши `main()`: вызови `draw_banner("Adventure Workshop")` и замени `"?"` на `ask_yes_no("Ready to build helper functions?")`.

## Пример кода

**Файл: [solution/helpers.py](solution/helpers.py)** — готовая версия. Загляни сюда, если застрял на TODO.

```python
# helpers.py
# Adventure Workshop — reusable recipe functions

def draw_banner(text):
    print("===")
    print(text)
    print("===")


def ask_yes_no(question):
    answer = input(f"{question} (yes/no): ").lower().strip()
    if answer in ("y", "yes"):
        return "yes"
    return "no"


def main():
    draw_banner("Adventure Workshop")
    answer = ask_yes_no("Ready to build helper functions?")
    print(f"You answered: {answer}")


main()
```

## Уголок отладки

**Проблема:** Ты написал `draw_banner("Adventure Workshop")` внутри `def main()`, но забыл **вызвать** `main()` в конце файла. Скрипт запускается и завершается без вывода.

**Причина:** Определение функции только **сохраняет** рецепт. Python не выполняет шаги, пока ты не **вызовешь** функцию по имени: `main()`.

**Исправление:** Убедись, что последняя строка файла — `main()` (без отступа — на верхнем уровне). Запусти снова.
