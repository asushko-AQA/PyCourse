## Объяснение

Добро пожаловать в **Игровую лабораторию**! Turtle рисовал команды одну за другой. **Pygame** другой — у него есть **игровой цикл**, который крутится много раз в секунду: события → обновление → отрисовка → показ кадра.

| Часть | Что делает |
|-------|------------|
| `import pygame` | Подключает игровой набор (`pip install pygame`) |
| `pygame.init()` | Запускает системы Pygame |
| `pygame.display.set_mode((w, h))` | Открывает окно шириной `w` и высотой `h` |
| `pygame.QUIT` | Событие, когда игрок нажал **крестик** окна |
| `pygame.display.flip()` | Показывает то, что ты нарисовал в этом кадре |
| `clock.tick(60)` | Целимся примерно в 60 кадров в секунду |

**Установка один раз (внутри venv):** Можно взять `.venv` из Курса 2 или создать новый в корне проекта.

```text
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install pygame
```

**Mac/Linux:** `source .venv/bin/activate`, затем `pip install pygame`.

Проверка:

```text
python -c "import pygame; print(pygame.version.ver)"
```

### Шаг 5: Пройди игровой цикл глазами

Каждый кадр:

1. `pygame.event.get()` — есть клики, выход, клавиши?
2. Если `QUIT` → `running = False`
3. `screen.fill(...)` — заливка фона
4. `pygame.display.flip()` — показать кадр
5. `clock.tick(60)` — чуть подождать ради ~60 FPS

Когда `running` станет `False`, выходим из `while` и вызываем `pygame.quit()`.

## Пример кода

**Файл: [starter/game.py](starter/game.py)** (готовая форма совпадает с решением)

```python
import pygame

pygame.init()

screen = pygame.display.set_mode((640, 480))
pygame.display.set_caption("My First Pygame Window")

clock = pygame.time.Clock()
running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((30, 30, 80))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

## Уголок отладки

**Проблема:** `ModuleNotFoundError: No module named 'pygame'`

**Причина:** Pygame не установлен в том Python, которым ты запускаешь файл — часто venv **не активирован**, или пакет попал в другое окружение.

**Исправление:**

1. Активируй `.venv` (в приглашении видно `(.venv)`).
2. Снова `pip install pygame`.
3. Проверь: `python -c "import pygame; print(pygame.version.ver)"`.
4. Запусти `python starter\game.py` из **того же** терминала.
