## Объяснение

Вчера ты открыл портал. Сегодня его **раскрасим**. В Pygame цвет — три числа: **R**ed, **G**reen, **B**lue — каждое от **0** (выкл.) до **255** (на полную).

| RGB | Как выглядит |
|-----|--------------|
| `(255, 0, 0)` | Чистый красный |
| `(0, 255, 0)` | Чистый зелёный |
| `(0, 0, 255)` | Чистый синий |
| `(255, 255, 255)` | Белый |
| `(0, 0, 0)` | Чёрный |
| `(30, 30, 80)` | Тёмно-синий (урок 1.1) |

Вызывай `screen.fill((r, g, b))` **каждый кадр**, затем чуть меняй `r`, `g` или `b`. Небо медленно меняется — магия через математику!

Держи каналы в диапазоне:

```python
r = (r + 1) % 256
```

`% 256` возвращает 256 обратно к 0 — всегда в законном диапазоне 0–255.

## Пример кода

**Файл: [solution/game.py](solution/game.py)** (цель после TODO)

```python
import pygame

pygame.init()

WIDTH = 640
HEIGHT = 480
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Color Caster")

clock = pygame.time.Clock()
running = True

r = 40
g = 80
b = 160

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((r, g, b))
    r = (r + 1) % 256

    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

## Уголок отладки

**Проблема:** Окно чёрное / цвет не меняется.

**Причина:** Забыл `screen.fill((r, g, b))`, или не обновляешь `r`/`g`/`b`, или обновляешь цвет **до** заливки нулями.

**Исправление:** Сначала `fill` **текущим** `(r, g, b)`, **потом** сдвиг канала, **потом** `flip()`. Порядок важен для того, что ты видишь в этом кадре.
