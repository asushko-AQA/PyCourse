## Объяснение

В уроке 1.3 коробка двигалась как `x = x + 3` **каждый кадр**. Это тайно привязывает скорость к частоте кадров:

| Компьютер | Кадров в секунду | Ощущение при `+ 3` за кадр |
|-----------|------------------|----------------------------|
| Медленный ноутбук | ~30 FPS | Вялый рейс |
| Игровой ПК | ~120 FPS | Коробка телепортируется |

**Дельта-время** (`dt`) — «сколько **секунд** прошло с прошлого кадра?» Двигайся в **пикселях в секунду**:

```python
dt = clock.tick(60) / 1000   # tick возвращает миллисекунды
x = x + speed * dt           # speed, например, 200 пикселей/секунду
```

`clock.tick(60)` и целится в 60 FPS, **и** сообщает реальное прошедшее время. Деление на `1000` переводит миллисекунды → секунды.

Держи `x` как **float** (`50.0`). При рисовании — `int(x)`, чтобы `draw.rect` получил целые пиксели.

## Пример кода

**Файл: [solution/game.py](solution/game.py)**

```python
import pygame

pygame.init()

WIDTH = 640
HEIGHT = 480
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Time Slider")

clock = pygame.time.Clock()
running = True

x = 50.0
y = 220.0
box_w = 50
box_h = 50
speed = 200  # пикселей в секунду

while running:
    dt = clock.tick(60) / 1000

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    x = x + speed * dt

    if x > WIDTH:
        x = -box_w

    screen.fill((15, 18, 32))
    pygame.draw.rect(screen, (80, 220, 180), (int(x), int(y), box_w, box_h))
    pygame.display.flip()

pygame.quit()
```
