## Explanation

Проект **№2** в Блоке 4 — **Prism Dash**: свой авто-бегун с **процедурными неоновыми фигурами** (без чужих картинок).

В бегуне герой часто остаётся слева, а **уровень едет**:

| Часть | Идея |
|-------|------|
| X героя | Фиксированный `PLAYER_X` (куб не уползает вправо) |
| Прокрутка мира | Каждый кадр: `world_x += SCROLL * dt` |
| Рисование плитки | `screen_x = tile_world_x - int(world_x)` |

Думай о `world_x` как о «сколько пикселей уровень уже прошёл мимо тебя».

---

### Step 1: Увеличивай `world_x`

После `dt = clock.tick(60) / 1000`:

```python
world_x += SCROLL * dt
```

---

### Step 2: Прокрути декоративные блоки

Для каждого `"#"` в строке паттерна:

```python
sx = i * TILE_W - int(world_x)
if -TILE_W < sx < WIDTH + TILE_W:
    block = pygame.Rect(sx, GROUND_Y - 56, TILE_W, 56)
    pygame.draw.rect(surface, (70, 120, 255), block, border_radius=4)
```

## Debug Corner

**Проблема:** Блоки дёргаются или телепортируются.

**Причина:** Забыли `int(world_x)` или перепутали modulo и на `i`, и на `world_x`.

**Fix:** Используй простую формулу `i * TILE_W - int(world_x)`, как в уроке 4.2 для труб.
