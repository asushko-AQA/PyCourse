## Explanation

У тебя уже есть **прокрутка** (4.4) и **прыжок + вращение** (4.5). Теперь собери полный цикл, как в уроках 2.4 и 4.3:

| Состояние | Что видит игрок |
|-----------|-----------------|
| `start` | Титул, лучший %, SPACE — старт |
| `playing` | Бег, прыжки, полоса прогресса |
| `game_over` | Удар о шип — `attempts++`, SPACE → титул |
| `win` | Достигнуто 100% строки уровня |

**Данные уровня** — одна строка, один символ на плитку (ширина `TILE_W` пикселей):

| Символ | Значение |
|--------|----------|
| `_` | Только ровная земля |
| `#` | Возвышенная платформа, на которую можно приземлиться |
| `^` | Шип в полу — `colliderect` → рестарт |

```python
LEVEL = "____##__^^__####__^^__##__^^____####____"
```

**Прогресс:** `int(world_x / len(LEVEL) / TILE_W * 100)` с ограничением 100.  
**Ускорение:** `BASE_SCROLL + progress_pct() * 2`.  
**Рекорд сессии:** обновляй `best_progress`, когда забег заканчивается.

---

### Step 1: `start_run()` и `die()`

Сбрось `world_x`, физику игрока, `state = PLAYING`.  
В `die()`: `attempts += 1`, при необходимости подними `best_progress`, `state = GAME_OVER`.

---

### Step 2: Рисование и столкновения уровня

Для каждой плитки `i`: `sx = i * TILE_W - int(world_x)`.  
Собирай `Rect` шипов чуть уже для честных попаданий. Треугольники — для красоты; логика — по rect.

---

### Step 3: Полоса прогресса + HUD

Широкая полоса внизу; ширина заливки = `progress_pct() %`. Покажи попытки и лучший %.

---

### Step 4: Условие победы

Когда `world_x >= len(LEVEL) * TILE_W` → `state = WIN` и праздник на экране.
