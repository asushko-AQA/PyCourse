## Block 5 readiness checklist (Glow Worm)

- [ ] `segments` is a list of `(col, row)` cells; `direction` is a `(dc, dr)` tuple
- [ ] Arrow keys queue direction; no instant 180° U-turn into the body
- [ ] Timer step moves the worm one cell per tick
- [ ] Food spawns on empty cells; eating grows the worm and bumps score
- [ ] Wall or self hit ends the run
- [ ] Start → play → game over → restart; session **best score**; speed ramps with score

## Block 5 readiness checklist (Bounce Forge)

- [ ] Ball uses `(ball_vx, ball_vy)` and `dt`; walls flip the correct velocity sign
- [ ] Paddle `hit_frac` steers the ball angle; **lives** drop when the ball falls through
- [ ] `bricks` is a `list` of `Rect`; side detection flips `vx` or `vy`; `score` rises
- [ ] Title / play / win / game over; **LEVEL_PATTERNS**; session **high_score**; optional **Pong** with **P**

## Block 5 readiness checklist (Orbit Guard)

- [ ] Patrol ship slides on the bottom; `player_bolts` list with cooldown and off-screen cleanup
- [ ] Invader **grid** marches sideways; at edges flip `march_dir` and `step_down`
- [ ] Bolt ↔ invader removes both; enemy bolts; **shields** wear down; **lives** and **score**
- [ ] **Waves** speed up; bonus **UFO**; start / wave clear / game over / victory; session **high_score**

## Block 5 readiness checklist (Mine Whisper)

- [ ] `grid` is a 2D list of cell dicts; `mouse_to_cell` maps clicks to `(col, row)`
- [ ] Mines place **after first click**; safe zone around that click has no mines
- [ ] `neighbors` counts adjacent mines; digits `1`–`8` render on reveal
- [ ] Zero regions **flood-fill** (recursive idea + stack implementation); right-click **flags**
- [ ] Difficulty presets; mine counter; timer; win / lose with mine reveal; session **best time**

## Block 5 readiness checklist (Merge Magic)

- [ ] `board` is a 4×4 list of ints; `0` means empty
- [ ] `RUNE_COLORS` tints tiles; numbers drawn in the center
- [ ] `merge_row` compresses, merges once per pair, compresses again (pure function)
- [ ] Four directions via reverse / transpose; **spawn only when board changed**
- [ ] Score tracks merges; **2048** win with continue; **game over** when no moves
- [ ] **Undo** one step; session **best_score**; optional slide glow animation

## Block 5 readiness checklist (Twin Cards)

- [ ] `build_deck` makes each `symbol` id **exactly twice**, then `random.shuffle`
- [ ] Cards are dicts with `col`, `row`, `symbol`, `face_up`, `matched`
- [ ] Draw purple **backs** vs colorful **shape symbols** (no image files)
- [ ] Click flow: `idle` → `first` → `waiting`; **no** `time.sleep` in the game loop
- [ ] `wait_timer` flips non-matching cards back; matches stay open
- [ ] Full game: moves + elapsed timer; sizes **4×3**, **4×4**, **6×4**
- [ ] Win overlay with **star rating** by moves; **R** restart; session **best moves**
