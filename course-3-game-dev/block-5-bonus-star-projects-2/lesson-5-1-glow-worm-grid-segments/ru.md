## Объяснение

Первый ★-проект Блока 5 — **Glow Worm**: добрая **змейка на сетке** из **неоновых кружков** (свой стиль; без чужих спрайтов).

Тело червяка — один **список** клеток:

```python
segments = [(8, 8), (7, 8), (6, 8)]  # голова первая — каждая пара (col, row)
```

- **`col`** — столбец (0 слева).
- **`row`** — строка (0 сверху).
- **`direction`** — кортеж `(dc, dr)`: сдвиг на один шаг.
  - Вправо `(1, 0)`, влево `(-1, 0)`, вверх `(0, -1)`, вниз `(0, 1)`.

**Зачем таймер?** Стрелки **выбирают** направление, а шаг по сетке — **раз в `MOVE_INTERVAL` секунд**, а не 60 раз в секунду.

**Без разворота на 180°:** при движении вправо мгновенный «влево» врезался бы в шею. Пиши направление в `pending_dir` и проверяй `is_opposite`.

### Step 3: Один шаг по сетке

В `step_worm`:

1. Скопируй `pending_dir` в `direction`.
2. Голова: `(hc, hr) = segments[0]`.
3. `new_head = (hc + dc, hr + dr)`.
4. **Только урок 5.1:** если клетка за бортом — `return` (конец игры в 5.2).
5. Сдвиг: `segments = [new_head] + segments[:-1]`.

---

### Step 4: Ввод и таймер

```python
move_timer += dt
if move_timer >= MOVE_INTERVAL:
    move_timer = 0.0
    step_worm()
```

Стрелки меняют `pending_dir`, если направление **не противоположно** `direction`.

## Debug Corner

**Проблема:** Червяк мчаится или дёргается.

**Причина:** `step_worm()` каждый кадр, а не по `MOVE_INTERVAL`.

**Решение:** Копи `dt` в `move_timer`, сбрасывай после шага.

**Проблема:** Разворот «в спину» ломает игру.

**Причина:** Меняешь `direction` без `is_opposite`.

**Решение:** Обновляй `pending_dir` только если направление не противоположно.
