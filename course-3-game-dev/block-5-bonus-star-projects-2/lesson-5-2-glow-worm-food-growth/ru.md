## Объяснение

Неоновый след ожил — пора **ловить искры-еду** и **удлиняться** после укуса.

В 5.1 хвост всегда укорачивался:

```python
segments = [new_head] + segments[:-1]
```

Если голова на **еде**, хвост **остаётся** — червяк вырастает на один сегмент:

```python
grow = new_head == food
segments = [new_head] + segments
if not grow:
    segments.pop()
```

**Появление еды:** `spawn_food()` выбирает случайную `(col, row)` вне `segments`. `set(segments)` быстро проверяет занятость.

**Столкновения:**

- **Стена** — голова за пределами поля → `alive = False`
- **Себя** — `segments[0] in segments[1:]` → укусил своё тело

**Рестарт:** когда `alive` ложно, **SPACE** сбрасывает червяка, еду, счёт и снова `alive = True`.
