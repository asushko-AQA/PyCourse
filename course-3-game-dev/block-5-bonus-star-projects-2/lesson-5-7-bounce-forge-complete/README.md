## What you'll build / Что ты создашь

**EN:** Ship **Bounce Forge**: **level patterns**, **speed-up**, **start / win / game over**, **session best**, and optional **2-player Pong** with **P** on the title.

## What you'll learn / Что ты узнаешь

- `state` like Glow Worm 5.3
- `high_score` on breakout runs
- `P` toggles Pong: two anvil paddles, first to 5
