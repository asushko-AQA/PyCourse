## 2. Условные обозначения

**Серьёзность**

- **critical** — типичный ученик не может пройти шаг/урок/курс по инструкции, решение падает или система проверки/прогресса даёт неверный результат без обходного пути.
- **major** — вводит в заблуждение (неверный вывод/ответ/инструкция), стартер не решается или уже содержит решение, существенное расхождение EN/RU, сломанная навигация, нарушение целостности прогресса.
- **minor** — опечатки, мелкие несоответствия, нарушения правил стиля, неудобство без блокировки.
- **cosmetic** — оформление, косметика.

**Сокращения путей.** `C1` = `course-1-python-basics`, `C2` = `course-2-web-apps`; `b2` = `block-2-*`; `l2.3` = `lesson-2-3-*` (например `C1/b3/l3.2` = `course-1-python-basics/block-3-making-choices/lesson-3-2-if-elif-else`). Номера строк — строки соответствующего файла. Скриншоты — в `docs/qa/screenshots/`.

**Нумерация ID.** `PL-xx` — платформа, `C1-xx` — Курс 1, `C2-xx` — Курс 2, `CT-xx` — сквозные. Номера `PL-01` и `PL-16` не используются (материалы про окружение/деплой сняты по указанию владельца).

## 4. Топ-5 самых важных проблем

1. **C1-01 (critical)** — самая первая команда в курсе (`cd Documents\PyCourse` в уроке 1.1) падает: терминал VS Code уже открыт в папке проекта. Ученик упирается в ошибку до урока про ошибки (то же допущение в 1.5; вслед за ним ломается и `cd` в 1.2 — C1-02).
2. **C2-01 (critical)** — Курс 2: `.venv` создаётся в папке урока 0.1, а урок 1.1 активирует его из корня репозитория; капстоуны лежат в корне. По инструкции активация не находит venv, дальше весь Flask-курс зависит от этого.
3. **C1-06 / C1-07 (major)** — в 13 уроках Курса 1 (блоки 2–5, включая капстоуны 3.4, 4.4, 5.3) `starter/` — готовое решение (в 14 файлах исполняемый код совпадает с `solution/` один в один) с `# TODO`-комментариями поверх рабочего кода; ключевые навыки (ветвления, циклы, функции, f-строки) ученик не пишет, капстоуны сводятся к «скопируй и запусти».
4. **PL-03 + CT-01 (major)** — награда за квиз не зависит от результата (0 из 4 с первой попытки → «+10 XP», `quizPerfect: true`, урок засчитан), а верные ответы почти всегда `a`/`b` (в 19 из 34 уроков все 5 ответов одинаковы; `d` нет ни разу). Звёзды и открытие следующих уроков обходятся без чтения.
5. **RU-версии существенно беднее EN (major)** — в `ru.md` нет капстоуна 3.4 и объяснения `break` (C1-10), капстоуна 5.3 (C1-11), блока про `not` (C1-12), устаревшее описание API в 4.4 (C1-14); в Курсе 2 RU-версии 0.1, 2.1–2.5 сокращены до заглушек без кода (C2-02, C2-04…C2-07). Плюс сломанные переходы между курсами (C1-03, C2-03).

## 7. Ограничения и что не засчитано как ошибка

- **Артефакт тестового окружения (не баг):** при обходе production-сборки на `http://127.0.0.1:3100` на каждой странице было по 9 ошибок консоли (CORS на `/auth/session`). Причина — origin `127.0.0.1:3100` не входит в список разрешённых для локального backend (по умолчанию `localhost:3000`); на `http://localhost:3000` ошибок CORS нет. По той же причине при `E2E_BASE_URL=http://127.0.0.1:3000` 4 из 12 UI-тестов Курсов 1–2 падали (с `localhost:3000` все проходят). Это особенность локального запуска, в таблицу не включена.
- Шаги для Windows (cmd/PowerShell, VS Code) проверялись по тексту и через эквиваленты на Linux; поведение macOS (AirPlay на порту 5000, C2-25) не воспроизводилось.
- Скриншоты сделаны в Chromium headless; анимации `whileInView` на карте курса не отображаются в full-page снимках — это артефакт снимков, не ошибка.
- Объём выборки по контенту: прочитаны все файлы уроков обоих курсов, но часть проверок выполнена субагентами-аудиторами; каждая находка с высокой серьёзностью (C1-01, C1-06…C1-09, C1-15, C2-01) и все платформенные находки перепроверены вручную. Остальные находки подтверждены воспроизводимой командой/diff на стороне аудитора.
- Ничего не исправлялось: отчёт содержит только предложения.
